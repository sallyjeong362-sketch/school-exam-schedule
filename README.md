# 시험대비 학교별 시간표 메이커

한 반에 여러 학교 학생이 섞여 있을 때, 시험대비 수업을 **학교별로** 다시 짜 주는 웹앱입니다.
설치·로그인 없이 `index.html` 하나로 동작하고, 입력한 내용은 브라우저에 자동 저장됩니다.

## 고려하는 조건
- 학생마다 다른 **타학원 시간표** (`월수금 17:00-19:00 수학학원 이동15` 처럼 한 줄씩 입력)
- 타학원 ↔ 우리학원 **이동시간** (학원별로 지정 가능, 안 적으면 기본값)
- 학교별 **하교 후 도착 가능 시각** (평일/주말)
- 우리 학원 **요일별 수업 가능 시간**, 학교별 **수업 길이**와 주당 횟수
- **동시에 열 수 있는 수업 수** (강의실·선생님 수) — 학교끼리 시간이 겹치지 않게

## 결과
- 학교별로 참석 인원이 가장 많은 시간을 회차마다 배정 (가능하면 다른 요일로 분산)
- 못 오는 학생과 **이유**(어느 학원, 이동시간 몇 분 때문인지) 표시
- 빠지는 학생을 위한 **보강 시간 제안**
- 참석 인원순 **대안 시간** 목록 → 버튼 하나로 회차 교체
- 주간 시간표 + 학교별 **가용 인원 지도**(히트맵), 인쇄/PDF 저장

`main`에 머지하면 GitHub Pages로 자동 배포됩니다 (`.github/workflows/deploy-pages.yml`).
